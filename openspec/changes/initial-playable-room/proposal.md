# Initial Playable Room

## Why

Validate that moving as a ghost, trying scares, and reading NPC reactions is understandable and enjoyable before building a full hotel or multiplayer system.

## What changes

- Add one isometric-inspired hotel room.
- Add one player-controlled ghost.
- Add one wandering NPC named Nora.
- Add Whisper, Cold Puff, and Object Nudge abilities.
- Add fear, scoring, energy, repetition, and failed-scare feedback.
- Add unit tests for the fear calculation.

## Out of scope

- Accounts, payments, public matchmaking, chat, backend services, final art, audio, possession controls, and multiple locations.
